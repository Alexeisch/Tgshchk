# 🤖 Telegram-бот «Планировщик задач»

Личный бот, который хранит ваши задачи, напоминает о них и раз в неделю присылает сводку.

## Что умеет бот

- **Главное меню**: «Здравствуйте, Имя!» и кнопки:
  «Новая задача» · «Все задачи» · ваши вкладки · «Новая вкладка» · «Выполненные» · «Настройки».
  Оформление сдержанное, чёрно-белое: вместо цветных эмодзи — простые символы, заголовки
  заглавными буквами, детали задачи — в блоке с серой полосой слева.
- **Понимает обычные сообщения.** Пишете:
  `6 числа встреча по адресу ул. Ленина 5 с Иваном Петровым в 15:00`
  Бот сам находит дату, время, место и человека, показывает, что понял, и спрашивает «Всё верно?».
  Понимает: `сегодня`, `завтра`, `послезавтра`, `6 числа`, `6 ноября`, `06.11`, `15.11.2027`,
  `в пятницу`, `через 3 дня`, `через неделю`, `в 15:00`, `в 9 утра`, `в 3 часа дня`, `в 8 вечера`.
- **Вкладки** — свои разделы для задач, например «Учёба» или «Работа». Создаются кнопкой
  «Новая вкладка» в главном меню и появляются там же. Во вкладке видны только её задачи;
  задачу можно создать сразу во вкладке (или просто написать её, находясь во вкладке),
  выбрать вкладку кнопкой «▤ Вкладка» при создании или перенести в другую позже.
  «Все задачи» показывают всё сразу, а задачи без вкладки остаются общими.
  Вкладку можно переименовать или удалить (её задачи — удалить или сделать общими).
- **Текущие задачи** с фильтрами «Сегодня / 7 дней / 30 дней / Все». Просроченные помечены знаком «!».
  Нажимаете на задачу — появляются кнопки:
  «Выполнено» · «Перенести» · «Изменить» · «Удалить».
- **Повторяющиеся задачи**: каждый день, по будням, каждую неделю, каждый месяц, каждый год.
  Можно написать прямо в тексте — `каждый день в 9:00 зарядка`, `по будням в 8:30 планёрка`,
  `каждую пятницу в 19:00 футбол`, `по средам бассейн`, `каждое 5 число оплатить квартиру`,
  `ежемесячно 10 числа платёж`, `каждый год 6 ноября день рождения мамы` — или нажать «↻ Повтор»
  при создании задачи или в её карточке. Когда отмечаете задачу выполненной, бот сам создаёт
  следующий раз. Кнопка «» Пропустить этот раз» переносит задачу на следующую дату без отметки.
  В списке повторяющиеся задачи помечены знаком «↻».
- **Перенос**: кнопками «+1 час», «+1 день», «+1 неделя» или текстом («завтра в 18:00», «12.11»).
- **Напоминания**: за сутки и за 2 часа до задачи. Если время не указано — накануне в 10:00
  и в сам день в 9:00. В напоминании есть кнопки «Выполнено» и «Перенести».
- **Отчёты** («Настройки» → «Отчёты») — картинка с диаграммами и проценты: сколько задач
  выполнено, не выполнено и ещё в процессе, сравнение с прошлым периодом и список невыполненного.
  Еженедельный приходит по воскресеньям (по умолчанию в 16:00), ежемесячный — в последний день
  месяца (по умолчанию в 20:00). Время и включение/выключение — в настройках.
  Получить отчёт в любой момент: команды `/summary` (неделя) и `/month` (месяц).
- **Погода** («Настройки» → «Погода»): укажите город и время — бот каждый день пришлёт
  короткий прогноз на сегодня: дождь/снег/облачно/ясно, сильный ветер (если есть)
  и температуру утром, днём и вечером. Погода прямо сейчас — команда `/weather`.
  Данные берутся с бесплатного сервиса [Open-Meteo](https://open-meteo.com), ключ не нужен.

# 📖 Пошаговая инструкция для macOS (для тех, кто никогда не программировал)

Займёт примерно 20–30 минут. Делайте шаги по порядку. Инструкция написана для MacBook.

## Шаг 1. Установите Python

Python — это язык программирования, на котором написан бот. Маку нужна программа,
которая умеет «читать» этот язык.

1. Откройте сайт <https://www.python.org/downloads/>.
2. Нажмите жёлтую кнопку **Download Python 3.13.x** (подойдёт и 3.12).
3. Откройте скачанный файл `.pkg` (он в папке «Загрузки») и нажимайте
   «Продолжить» → «Согласен» → «Установить». Мак попросит пароль — введите пароль от компьютера.
4. В конце откроется папка **Python 3.13** в Finder. Дважды щёлкните в ней файл
   **Install Certificates.command** — откроется окно, подождите надпись `[Process completed]`
   и закройте его. (Это нужно, чтобы Python мог безопасно подключаться к интернету.)

**Проверка:** откройте программу **Терминал** (нажмите `Cmd + Пробел`, напишите «Терминал»,
нажмите Enter), введите `python3 --version` и нажмите Enter. Должно появиться `Python 3.13.…`.

> Если вместо этого Мак предложит установить «инструменты разработчика командной строки» —
> значит, Python из шага 1 не установился. Повторите шаг 1.

## Шаг 2. Установите Visual Studio Code

VS Code — бесплатная программа от Microsoft, в которой удобно открывать и запускать код.

1. Откройте <https://code.visualstudio.com> и нажмите **Download for macOS**.
2. В «Загрузках» появится программа **Visual Studio Code** (если скачался `.zip` —
   дважды щёлкните его, чтобы распаковать). **Перетащите её в папку «Программы»** (Applications).
3. Запустите VS Code из Launchpad или папки «Программы». Если Мак спросит
   «Вы действительно хотите открыть?» — нажмите **Открыть**.
4. Установите расширение для Python: слева нажмите значок из четырёх квадратиков
   (**Extensions**, или `Cmd + Shift + X`), в поиске напишите `Python`, выберите **Python**
   от **Microsoft** и нажмите **Install**.

> Не хотите ставить VS Code? Бота можно запустить и просто из Терминала — см.
> раздел [«Запуск без VS Code»](#-запуск-без-vs-code-только-терминал) ниже.

## Шаг 3. Создайте бота в Telegram и получите токен

Токен — это «пароль» бота, по которому программа будет управлять им.

1. В Telegram найдите в поиске **@BotFather** (с синей галочкой) и откройте чат.
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте команду `/newbot`.
4. BotFather спросит **имя** бота — напишите любое, например `Мой планировщик`.
5. Затем спросит **username** — это адрес бота, он должен быть латиницей и заканчиваться на `bot`,
   например `alexey_tasks_bot`. Если занято — придумайте другой.
6. BotFather пришлёт сообщение с токеном — строкой вида
   `7123456789:AAHk3j...`. **Скопируйте её** и никому не показывайте.

## Шаг 4. Скачайте код бота

1. Откройте ссылку:
   <https://github.com/alexeisch/tgshchk/archive/refs/heads/claude/telegram-task-manager-bot-i6cg7g.zip>
   (если вы не вошли в GitHub, сначала войдите — репозиторий может быть приватным).
   Либо откройте страницу репозитория на GitHub, выберите ветку
   `claude/telegram-task-manager-bot-i6cg7g` и нажмите зелёную кнопку **Code → Download ZIP**.
2. В «Загрузках» появится архив — дважды щёлкните его, чтобы распаковать
   (Safari часто распаковывает сам).
3. Переложите получившуюся папку в удобное место, например в «Документы»,
   и для удобства переименуйте её в `TaskBot`.
4. Внутри должны быть файлы: `bot.py`, `database.py`, `date_parser.py`, `requirements.txt`, `README.md`.

> Файлы, имя которых начинается с точки (`.env.example`, `.gitignore`), Finder по умолчанию
> **скрывает**. Показать их: в Finder нажмите `Cmd + Shift + .` (точка). Нажмите ещё раз, чтобы снова скрыть.
> В VS Code они видны всегда.

## Шаг 5. Откройте папку в VS Code

1. В VS Code: меню **File → Open Folder…** (Файл → Открыть папку).
2. Выберите папку `TaskBot` (ту, где лежит `bot.py`) → **Open**.
3. Если спросит «Do you trust the authors of the files in this folder?» —
   нажмите **Yes, I trust the authors**.
4. Слева появится список файлов.

## Шаг 6. Создайте виртуальное окружение и установите библиотеки

Виртуальное окружение — это отдельная «коробка» внутри папки проекта, куда скачиваются
библиотеки бота (например, для работы с Telegram). Делается один раз.

1. Откройте терминал внутри VS Code: верхнее меню **Terminal → New Terminal**.
   Внизу появится окно со строкой вида `имя@MacBook TaskBot %` — это значит,
   что терминал уже «стоит» в папке бота.
2. Скопируйте в терминал эту команду и нажмите **Enter** (создаёт окружение, ответа не будет —
   это нормально):

   ```
   python3 -m venv .venv
   ```

3. Затем эту (включает окружение — в начале строки появится `(.venv)`):

   ```
   source .venv/bin/activate
   ```

4. И эту (скачивает библиотеки, займёт около минуты; в конце будет `Successfully installed ...`):

   ```
   pip install -r requirements.txt
   ```

5. Если справа внизу VS Code спросит «We noticed a new environment… select it for the workspace?» —
   нажмите **Yes**. Если не спросил — нажмите `Cmd + Shift + P`, начните печатать
   `Python: Select Interpreter`, выберите эту команду и затем вариант с **`.venv`**.

> Если на пункте 2 Мак предложил установить «инструменты разработчика командной строки» —
> значит, Python из шага 1 не установлен. Вернитесь к шагу 1.

## Шаг 7. Впишите токен (файл `.env`)

1. Слева нажмите на файл **`.env.example`** правой кнопкой (или двумя пальцами на тачпаде)
   → **Copy**, затем правой кнопкой на пустое место в списке файлов → **Paste**.
   Появится файл `.env copy.example`.
2. Нажмите на него правой кнопкой → **Rename…** и переименуйте ровно в **`.env`**
   (с точкой в начале, без других слов).
3. Откройте `.env`. В строке `BOT_TOKEN=сюда_вставьте_токен` замените текст после `=`
   на ваш токен из шага 3:

   ```
   BOT_TOKEN=7123456789:AAHk3j...
   ```

   Без пробелов и кавычек.
4. Если вы живёте не по московскому времени — поменяйте `TIMEZONE`
   (например, `Asia/Yekaterinburg`, `Asia/Novosibirsk`, `Europe/Kaliningrad`).
   От этого зависит, когда приходят напоминания и сводка.
5. (Необязательно, но полезно) Чтобы ботом не мог пользоваться никто, кроме вас: напишите
   боту **@userinfobot** в Telegram, он пришлёт ваш **Id** (число). Впишите его:
   `ALLOWED_USERS=123456789`.
6. Сохраните: `Cmd + S`.

## Шаг 8. Запустите бота 🚀

1. Слева откройте файл **`bot.py`**.
2. Справа сверху нажмите треугольник **▶ (Run Python File)**.
3. Внизу откроется терминал, где появится строка
   `Бот запущен! Откройте его в Telegram и отправьте /start.`
4. Откройте Telegram, найдите своего бота по username из шага 3, нажмите **Start**.
5. Должно появиться «Здравствуйте, (ваше имя).» и кнопки меню. Готово!

**Остановить бота:** щёлкните в окно терминала внизу и нажмите `Control + C`
(именно **Control**, а не Cmd).
**Запустить снова:** снова ▶ в файле `bot.py`.

## 💻 Запуск без VS Code (только Терминал)

Если VS Code ставить не хочется, хватит встроенного приложения **Терминал**.
Шаги 1, 3 и 4 выше выполните так же, а дальше:

1. Откройте **Терминал** (`Cmd + Пробел` → «Терминал»).
2. Напечатайте `cd ` (с пробелом в конце), **перетащите мышкой папку `TaskBot`** из Finder
   прямо в окно Терминала и нажмите Enter. Так Терминал «зайдёт» в эту папку.
3. **Один раз** выполните по очереди эти команды (каждую — Enter и дождаться окончания):

   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   open -e .env
   ```

   Последняя команда откроет файл настроек в TextEdit. Впишите токен после `BOT_TOKEN=`
   (см. шаг 7), сохраните (`Cmd + S`) и закройте TextEdit.
4. Запустите бота:

   ```
   python bot.py
   ```

   Пока окно Терминала открыто — бот работает. Остановить: `Control + C`.

**В следующие разы** достаточно трёх команд:

```
cd ~/Documents/TaskBot
source .venv/bin/activate
python bot.py
```

(Если папка лежит в другом месте — после `cd ` перетащите её в Терминал, как в пункте 2.)

## Как пользоваться

| Что хочу | Что делать |
|---|---|
| Добавить задачу | Просто напишите её боту или нажмите «Новая задача» |
| Бот неправильно понял дату | В карточке «Проверьте задачу» нажмите «Дата и время» |
| Посмотреть задачи | «Все задачи» или нужная вкладка, сверху выбрать «Сегодня / 7 дней / 30 дней / Все» |
| Создать вкладку | Главное меню → «Новая вкладка» → написать название |
| Задача во вкладку | Открыть вкладку → «Задача во вкладку» (или просто написать задачу, пока вкладка открыта) |
| Переложить задачу в другую вкладку | Открыть задачу → «▤ Вкладка» |
| Переименовать / удалить вкладку | Открыть вкладку → «⋯ Вкладка» |
| Отметить выполненной | Открыть задачу → «Выполнено» (или кнопка прямо в напоминании) |
| Перенести | Открыть задачу → «Перенести» → кнопка или текст, например `завтра в 18:00` |
| Сделать задачу повторяющейся | Напишите в тексте «каждый день», «по пятницам», «каждое 5 число»… или откройте задачу → «↻ Повтор» |
| Пропустить один раз | Открыть повторяющуюся задачу → «» Пропустить этот раз» |
| Отключить повтор | Открыть задачу → «↻ Повтор» → «Не повторять» |
| Изменить текст | Открыть задачу → «Изменить» → отправить новый текст |
| Вернуть выполненную задачу | «Выполненные» → задача → «Вернуть в текущие» |
| Главное меню | Команда `/start` или `/menu` |
| Отчёт прямо сейчас | Команда `/summary` (неделя) или `/month` (месяц) |
| Настроить отчёты | «Настройки» → «Отчёты» → время и включение для недельного и месячного |
| Настроить погоду | «Настройки» → «Погода» → указать город и время |
| Погода прямо сейчас | Команда `/weather` |

**Советы по формулировкам:**
- Имя человека пишите с заглавной буквы после «с»: `с Иваном`, `со Светланой`.
- Адрес — после слов «по адресу»: `по адресу ул. Ленина 5, кв 12`.
- Если указано только время (`в 15:00 созвон`), задача ставится на сегодня
  (или на завтра, если это время сегодня уже прошло).
- Если написано `6 числа`, а 6-е в этом месяце уже прошло, бот поставит 6-е следующего месяца.

## ❗ Важно знать

- **Бот работает, только пока запущен** — то есть пока открыт VS Code (или окно Терминала)
  с запущенным ботом, а MacBook не спит и подключён к интернету.
  **Если закрыть крышку MacBook, он засыпает — и бот перестаёт работать.**
  Напоминания, «проспанные» за это время, бот пришлёт после пробуждения
  (если встреча ещё не началась).
- Чтобы MacBook не уснул сам, пока вы за ним не сидите, запускайте бота так
  (в терминале, вместо `python bot.py`):

  ```
  caffeinate -i python bot.py
  ```

  Это не даёт Маку засыпать, пока работает бот. Но при **закрытой крышке** Мак всё равно уснёт
  (если он не подключён к внешнему монитору и зарядке).
- Чтобы бот работал круглосуточно, независимо от ноутбука, его можно перенести на сервер (VPS)
  или хостинг вроде PythonAnywhere / Railway / Timeweb Cloud — это следующий шаг, когда освоитесь.
- Все задачи хранятся в файле **`tasks.db`** в папке проекта (появится после первого запуска).
  Не удаляйте его — иначе пропадут задачи. Для резервной копии просто скопируйте этот файл.
- **Никому не показывайте токен** и файл `.env`. Если токен «утёк», в @BotFather отправьте
  `/revoke`, получите новый и впишите его в `.env`.

## 🛠 Если что-то не работает

| Сообщение / проблема | Решение |
|---|---|
| `Не найден токен бота` | Нет файла `.env` или в нём не вписан токен (шаг 7). Имя файла должно быть ровно `.env` |
| `ModuleNotFoundError: No module named 'telegram'` | Не установлены библиотеки (шаг 6) или запущен «не тот» Python. В VS Code: `Cmd + Shift + P` → `Python: Select Interpreter` → выберите вариант с `.venv`. В Терминале: сначала `source .venv/bin/activate` |
| `command not found: python` | Окружение не включено — выполните `source .venv/bin/activate` (или используйте `python3`) |
| `command not found: pip` | То же самое: `source .venv/bin/activate`, либо `python3 -m pip install -r requirements.txt` |
| `SSL: CERTIFICATE_VERIFY_FAILED` | Не выполнен пункт 4 шага 1 — запустите **Install Certificates.command** из папки «Программы → Python 3.13» |
| `InvalidToken` / `Unauthorized` | Токен скопирован с ошибкой — скопируйте заново из @BotFather |
| `Conflict: terminated by other getUpdates request` | Бот запущен дважды. Остановите все запуски (`Control + C`, закройте лишние терминалы) и запустите один раз |
| Бот молчит в Telegram | Проверьте, что в терминале есть строка «Бот запущен!» и нет красных ошибок; что Мак не спит |
| Напоминания приходят не в то время | Проверьте `TIMEZONE` в `.env` и перезапустите бота |
| Не вижу файл `.env` в Finder | Он скрыт, так как начинается с точки. В Finder нажмите `Cmd + Shift + .` |

| `bot.py` | Главный файл: меню, кнопки, напоминания, сводка. **Его и запускаем** |
| `date_parser.py` | «Понимание» текста: ищет дату, время, адрес и человека в сообщении |
| `database.py` | Сохранение задач и настроек в файл `tasks.db` |
| `weather.py` | Прогноз погоды (сервис Open-Meteo) |
| `reports.py` | Отчёты за неделю и месяц: статистика и диаграммы |
| `requirements.txt` | Список библиотек для установки |
| `.env.example` | Образец файла настроек |
