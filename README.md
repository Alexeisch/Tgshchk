# 🤖 Telegram-бот «Планировщик задач»

Личный бот, который хранит ваши задачи, напоминает о них и раз в неделю присылает сводку.

## Что умеет бот

- **Главное меню**: «Здравствуйте, Имя!» и три кнопки:
  ➕ Создать новую задачу · 📋 Текущие задачи · ✅ Выполненные задачи.
- **Понимает обычные сообщения.** Пишете:
  `6 числа встреча по адресу ул. Ленина 5 с Иваном Петровым в 15:00`
  Бот сам находит дату, время, место и человека, показывает, что понял, и спрашивает «Всё верно?».
  Понимает: `сегодня`, `завтра`, `послезавтра`, `6 числа`, `6 ноября`, `06.11`, `15.11.2027`,
  `в пятницу`, `через 3 дня`, `через неделю`, `в 15:00`, `в 9 утра`, `в 3 часа дня`, `в 8 вечера`.
- **Текущие задачи** с фильтрами «Сегодня / 7 дней / 30 дней / Все». Просроченные помечены ⚠️.
  Нажимаете на задачу — появляются кнопки:
  ✅ Отметить выполненной · 📅 Перенести · ✏️ Изменить · 🗑 Удалить.
- **Перенос**: кнопками «+1 час», «+1 день», «+1 неделя» или текстом («завтра в 18:00», «12.11»).
- **Напоминания**: за сутки и за 2 часа до задачи. Если время не указано — накануне в 10:00
  и в сам день в 9:00. В напоминании есть кнопки «Выполнено» и «Перенести».
- **Сводка за неделю** — каждое воскресенье в 16:00: сколько задач было, сколько выполнено (в %),
  что не сделано. Посмотреть сводку в любой момент: команда `/summary`.

# 📖 Пошаговая инструкция (для тех, кто никогда не программировал)

Займёт примерно 20–30 минут. Делайте шаги по порядку.

## Шаг 1. Установите Python

Python — это язык программирования, на котором написан бот. Компьютеру нужна программа,
которая умеет «читать» этот язык.

1. Откройте сайт <https://www.python.org/downloads/>.
2. Нажмите жёлтую кнопку **Download Python 3.13.x** (подойдёт и 3.12).
3. Запустите скачанный файл.
4. ⚠️ **Важно (Windows):** в самом первом окне установщика внизу поставьте галочку
   **«Add python.exe to PATH»**, затем нажмите **Install Now**.
5. Дождитесь надписи «Setup was successful» и закройте окно.

> На Mac: просто запустите скачанный `.pkg`-файл и нажимайте «Продолжить».

## Шаг 2. Установите PyCharm

PyCharm — это программа, в которой удобно открывать и запускать код.

1. Откройте <https://www.jetbrains.com/pycharm/download/>.
2. Скачайте **PyCharm** (бесплатной версии полностью достаточно — платная подписка не нужна).
3. Установите, как обычную программу (везде «Далее»). При первом запуске можно выбрать тему
   оформления и пропустить остальные настройки.

## Шаг 3. Создайте бота в Telegram и получите токен

Токен — это «пароль» бота, по которому программа будет управлять им.

1. В Telegram найдите в поиске **@BotFather** (с синей галочкой) и откройте чат.
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте команду `/newbot`.
4. BotFather спросит **имя** бота — напишите любое, например `Мой планировщик`.
5. Затем спросит **username** — это адрес бота, он должен быть латиницей и заканчиваться на `bot`,
   например `alexey_tasks_bot`. Если занято — придумайте другой.
6. BotFather пришлёт сообщение с токеном — строкой вида
   `7123456789:AAHk3j...`. **Скопируйте её** и никому не показывайте.

## Шаг 4. Скачайте код бота

**Самый простой способ — ZIP-архив:**

1. Откройте ссылку:
   <https://github.com/alexeisch/tgshchk/archive/refs/heads/claude/telegram-task-manager-bot-i6cg7g.zip>
   (если вы не вошли в GitHub, сначала войдите — репозиторий может быть приватным).
   Либо откройте страницу репозитория на GitHub, выберите ветку
   `claude/telegram-task-manager-bot-i6cg7g` и нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте архив (правой кнопкой → «Извлечь всё…») в удобное место,
   например в `Документы\TaskBot`.
3. Внутри должны быть файлы: `bot.py`, `database.py`, `date_parser.py`, `requirements.txt`,
   `.env.example`, `README.md`.

## Шаг 5. Откройте проект в PyCharm

1. Запустите PyCharm → **Open** (Открыть).
2. Выберите **папку** с файлами бота (ту, где лежит `bot.py`) → **OK**.
3. Если спросит «Trust project?» — нажмите **Trust Project**.
4. Слева появится список файлов проекта.

## Шаг 6. Настройте Python в проекте (виртуальное окружение)

Виртуальное окружение — это отдельная «коробка» для библиотек бота, чтобы они не мешали
другим программам.

1. PyCharm может сам показать жёлтую полоску сверху с предложением создать окружение
   (**Configure Python interpreter** / **Create a virtual environment**) — тогда просто
   согласитесь и нажмите **OK**, и переходите к шагу 7.
2. Если полоски нет:
   - Windows: меню **File → Settings**; Mac: **PyCharm → Settings**.
   - Слева: **Project: (имя папки) → Python Interpreter**.
   - Справа сверху **Add Interpreter → Add Local Interpreter…**
   - Выберите **Virtualenv** (или «Generate new»), в поле *Base python* должен быть Python 3.13
     → **OK** → ещё раз **OK**.

## Шаг 7. Установите библиотеки

Бот использует готовые библиотеки (например, для работы с Telegram). Их нужно скачать один раз.

1. Внизу PyCharm нажмите на значок **Terminal** (или меню **View → Tool Windows → Terminal**).
2. Убедитесь, что в начале строки терминала написано `(.venv)` или `(venv)` — значит,
   окружение включено.
3. Вставьте команду и нажмите **Enter**:

   ```
   pip install -r requirements.txt
   ```

4. Дождитесь окончания (появятся строки `Successfully installed ...`).

> Если пишет `pip не является командой` — закройте и снова откройте PyCharm,
> либо повторите шаг 6. Также можно попробовать `python -m pip install -r requirements.txt`.

## Шаг 8. Впишите токен (файл `.env`)

1. В PyCharm слева нажмите правой кнопкой на файл **`.env.example`** → **Copy** (Копировать),
   затем правой кнопкой на папку проекта → **Paste** (Вставить). В появившемся окне впишите новое
   имя: **`.env`** (с точкой в начале, без `.example`) → **OK**.
2. Откройте новый файл `.env` двойным щелчком.
3. В строке `BOT_TOKEN=сюда_вставьте_токен` замените текст после `=` на ваш токен из шага 3:

   ```
   BOT_TOKEN=7123456789:AAHk3j...
   ```

   Без пробелов и кавычек.
4. Если вы живёте не по московскому времени — поменяйте `TIMEZONE`
   (например, `Asia/Yekaterinburg`, `Asia/Novosibirsk`, `Europe/Kaliningrad`).
   От этого зависит, когда приходят напоминания и сводка.
5. (Необязательно, но полезно) Чтобы ботом не мог пользоваться никто, кроме вас: напишите боту
   **@userinfobot** в Telegram, он пришлёт ваш **Id** (число). Впишите его:
   `ALLOWED_USERS=123456789`.
6. Сохраните файл (**Ctrl+S**, на Mac **Cmd+S**; PyCharm обычно сохраняет сам).

## Шаг 9. Запустите бота 🚀

1. Слева откройте файл **`bot.py`**.
2. Нажмите правой кнопкой по тексту файла → **Run 'bot'**
   (или зелёный треугольник ▶ сверху справа).
3. Внизу откроется окно, где появится строка
   `Бот запущен! Откройте его в Telegram и отправьте /start.`
4. Откройте Telegram, найдите своего бота по username из шага 3, нажмите **Start**.
5. Должно появиться «Здравствуйте, (ваше имя)!» и три кнопки. Готово! 🎉

**Остановить бота:** красный квадрат ■ в окне запуска PyCharm.
**Запустить снова:** зелёный треугольник ▶.

## Как пользоваться

| Что хочу | Что делать |
|---|---|
| Добавить задачу | Просто напишите её боту или нажмите «➕ Создать новую задачу» |
| Бот неправильно понял дату | В карточке «Вот что я понял» нажмите «📅 Изменить дату/время» |
| Посмотреть задачи | «📋 Текущие задачи», сверху выбрать «Сегодня / 7 дней / 30 дней / Все» |
| Отметить выполненной | Открыть задачу → «✅ Отметить выполненной» (или кнопка прямо в напоминании) |
| Перенести | Открыть задачу → «📅 Перенести» → кнопка или текст, например `завтра в 18:00` |
| Изменить текст | Открыть задачу → «✏️ Изменить» → отправить новый текст |
| Вернуть выполненную задачу | «✅ Выполненные задачи» → задача → «↩️ Вернуть в текущие» |
| Главное меню | Команда `/start` или `/menu` |
| Сводка прямо сейчас | Команда `/summary` |

**Советы по формулировкам:**
- Имя человека пишите с заглавной буквы после «с»: `с Иваном`, `со Светланой`.
- Адрес — после слов «по адресу»: `по адресу ул. Ленина 5, кв 12`.
- Если указано только время (`в 15:00 созвон`), задача ставится на сегодня
  (или на завтра, если это время сегодня уже прошло).
- Если написано `6 числа`, а 6-е в этом месяце уже прошло, бот поставит 6-е следующего месяца.

## ❗ Важно знать

- **Бот работает, только пока запущен** — то есть пока открыт PyCharm, программа запущена (▶)
  и компьютер включён и подключён к интернету. Если выключить компьютер, напоминания не придут.
  Напоминания, «проспанные» за это время, бот пришлёт после запуска (если встреча ещё не началась).
  Чтобы бот работал круглосуточно, его можно перенести на сервер (VPS) или хостинг вроде
  PythonAnywhere / Railway / Timeweb Cloud — это следующий шаг, когда освоитесь.
- Все задачи хранятся в файле **`tasks.db`** в папке проекта (появится после первого запуска).
  Не удаляйте его — иначе пропадут задачи. Для резервной копии просто скопируйте этот файл.
- **Никому не показывайте токен** и файл `.env`. Если токен «утёк», в @BotFather отправьте
  `/revoke`, получите новый и впишите его в `.env`.

## 🛠 Если что-то не работает

| Сообщение / проблема | Решение |
|---|---|
| `Не найден токен бота` | Нет файла `.env` или в нём не вписан токен (шаг 8). Имя файла должно быть ровно `.env` |
| `ModuleNotFoundError: No module named 'telegram'` | Не установлены библиотеки (шаг 7) или PyCharm использует другой Python (шаг 6) |
| `InvalidToken` / `Unauthorized` | Токен скопирован с ошибкой — скопируйте заново из @BotFather |
| `Conflict: terminated by other getUpdates request` | Бот запущен дважды. Остановите все запуски (■) и запустите один раз |
| Бот молчит в Telegram | Проверьте, что внизу PyCharm есть строка «Бот запущен!» и нет красных ошибок |
| Напоминания приходят не в то время | Проверьте `TIMEZONE` в `.env` и перезапустите бота |

## Из чего состоит проект

| Файл | Что внутри |
|---|---|
| `bot.py` | Главный файл: меню, кнопки, напоминания, сводка. **Его и запускаем** |
| `date_parser.py` | «Понимание» текста: ищет дату, время, адрес и человека в сообщении |
| `database.py` | Сохранение задач в файл `tasks.db` |
| `requirements.txt` | Список библиотек для установки |
| `.env.example` | Образец файла настроек |
